# Category 6 — EventBridge Monday Scheduler

## Step 1 — Create Schedule

**Navigate:**
```
AWS Console → Amazon EventBridge → Schedules → Create schedule
```

**Fill exactly:**
```
Schedule name       : aws-weekly-report-schedule
Description         : Triggers weekly report email every Monday 7:30 AM IST
Group               : default
```

Click `Next`

---

## Step 2 — Set Schedule Pattern

```
Occurrence          : Recurring schedule
Schedule type       : Cron-based schedule
```

Cron expression — paste exactly:
```
0 2 ? * MON *
```

This means:
```
0 2 = 2:00 AM UTC = 7:30 AM IST
?   = any day of month
*   = every month
MON = every Monday
*   = every year
```

```
Flexible time window : Off
```

Click `Next`

---

## Step 3 — Set Target

```
Target API          : AWS Lambda  →  Invoke
Lambda function     : aws-weekly-report-sender
Payload             : {}
```

Click `Next`

---

## Step 4 — Settings

```
Action after schedule completion : NONE
Retry policy                     : ON
Maximum age of event             : 1 hour
Retry attempts                   : 2
```

**Permissions:**
```
Execution role      : Create new role for this schedule
Role name           : aws-eventbridge-weekly-report-role
```

Click `Next` → Review → `Create schedule` ✅
